# 项目经验维护

按关键词和适用范围检索相关记录，识别有证据、可复用且不含敏感信息的候选，不在重大任务前通读全部档案。

## 授权与位置

写入遵循全局 AGENTS.md 第 10 节及当前任务授权。技能不另行授予自动双写权限；用户暂停沉淀时停止写入。没有写入授权时仅列有价值的候选，不打断当前可继续的工作。

- 项目经验：项目 .learnings/LEARNINGS.md。
- 已验证的故障、原因及防复发方式：项目 .learnings/ERRORS.md。
- 已授权的长期项目规则：项目 AGENTS.md 或正式决策文档。
- 稳定全局偏好与跨项目经验：获授权后写入 /Users/guofu/.codex/GuofuProfile/ 对应文件；不得与项目层无条件双写。
- Codex 内置 memories 的写入遵循宿主专门机制，不用上述路径替代它。

## 处理

记录前搜索已有条目，合并重复证据，保留可追踪来源。升级规则前检查时间、适用范围、证据和冲突。偶发错误、未确认推测及重复出现本身，不足以升级永久规则。

记录至少包括：结论、证据、适用范围、时间；故障记录增加现象、原因、修复与下次避免方式。有实际写入时简要说明位置及内容。

需要详细记录格式时读取 references/record-formats.md。现有 scripts/、assets/ 与平台 references/ 仅在用户请求对应导出、安装或集成任务时检查和使用；平台集成须核对当前接口，不能把其他平台的 hook 配方当成 Codex 已生效配置。
